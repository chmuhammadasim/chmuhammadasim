## About me

I'm a Software Engineer at **SNSKIES Pvt Ltd**, based in Islamabad, Pakistan. I build software across the stack, with a strong interest in backend engineering, cybersecurity, cloud infrastructure, and systems design.

I enjoy turning complex requirements into practical, maintainable solutions — from application interfaces and APIs to infrastructure and security-focused platforms.

- **Primary focus:** Backend and full-stack engineering
- **Interested in:** Cybersecurity, cloud, distributed systems, and automation
- **Approach:** Secure by design, observable in production, maintainable over time

## Engineering principles

- **Security first:** Think about trust boundaries and threats early.
- **Keep systems understandable:** Choose maintainable designs over needless complexity.
- **Automate repeatable work:** Make deployments and operational tasks consistent.
- **Observe what you build:** Use telemetry and logs to understand system behavior.
- **Plan for failure:** Build recovery and resilience into the design.
