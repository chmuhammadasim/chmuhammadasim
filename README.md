## [05] // OPERATING PRINCIPLES

- `[01]` **SECURITY BY DESIGN** :: threat model before the first commit.
- `[02]` **SCALE WITH INTENT** :: leave room for requirements to grow.
- `[03]` **SIMPLICITY WINS** :: the architecture engineers can read is the architecture they can maintain.
- `[04]` **AUTOMATE THE REPEATABLE** :: pipelines over manual operations.
- `[05]` **OBSERVABILITY FIRST** :: if it can't be measured, it can't be trusted.
- `[06]` **DESIGN FOR FAILURE** :: assume breakage; plan recovery.
- `[07]` **MAINTAINABILITY IS A FEATURE** :: optimize for the next engineer.

<p align="center">
  <code>UNDERSTAND</code> -&gt; <code>DESIGN</code> -&gt; <code>BUILD</code> -&gt; <code>TEST</code> -&gt; <code>PROTECT</code> -&gt; <code>OBSERVE</code> -&gt; <code>IMPROVE</code>
</p>
